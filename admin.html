Google Apps Script Code & 5-Step Setup

  1. Open Google Sheets and create a blank spreadsheet named "MAM SCALEVIO Inquiries".
  2. Click Extensions > Apps Script in the top menu.
  3. Delete any existing code in Code.gs and paste the script code below.
  4. Click Deploy > New deployment > Select type Web app:
